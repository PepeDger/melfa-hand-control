# Управление манипулятором MELFA движениями кисти

Учебный проект СПбПУ. Локальный веб-пульт преобразует движения кисти, полученные с обычной камеры, в целевые углы шести осей MELFA RV-3SDB. Для проверки команд можно использовать встроенную модель в браузере.

## Быстрый запуск модели

1. Установите Python 3.11 для Windows.
2. Откройте PowerShell в папке проекта и выполните `.\StartMelfa.cmd --no-connect`. Оставьте окно запуска открытым. Если браузер не открылся, скопируйте полный адрес из окна запуска, включая часть после `#`.
3. Задайте ползунками целевой угол и нажмите «Выполнить». Пульт покажет движение модели.

## Управление кистью

1. Один раз запустите `SetupHandTracking.cmd`. Для установки пакетов требуется интернет.
2. В пульте выберите «Кисть → модель» и нажмите «Открыть камеру».
3. Покажите всю кисть ладонью к камере, нажмите «Калибровать / включить» и плавно двигайте кистью. Текущие и целевые углы видны в интерфейсе. Для остановки нажмите STOP или Esc.

Работу с физическим манипулятором проводите по инструкции своего стенда с ответственным за установку. Для подключения задайте согласованные параметры в `config.json`. В комплекте указан локальный адрес `127.0.0.1`.

## Тесты

В папке проекта запустите `python -m unittest discover -s tests -q`. Тесты используют имитаторы и локальные тестовые соединения.
